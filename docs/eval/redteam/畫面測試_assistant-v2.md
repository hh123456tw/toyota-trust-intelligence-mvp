## 症狀登記（卡片外問題）

| 步驟 | 畫面 |
|---|---|
| 我冷氣不冷 | 冷氣不在今天的檢查範圍，卡片上沒有它的資料，我不想亂猜。可以按下面的按鈕，請專員來幫你確認。 |
| 程式接著問 | 我先幫你把狀況記下來，技師看了會比較快。 |
| 題 1 | 是完全不冷，還是開一陣子才不冷？ → 點「開一陣子才不冷」 |
| 題 2 | 出風口的風量正常嗎？ → 點「變小」 |
| 題 3 | 有聞到怪味嗎？ → 點「沒有」 |
| 複述 | 好，我幫你記下了：冷氣，開一陣子才不冷，出風量變小，沒有怪味。按下面的按鈕，專員會帶著這些資訊過來。 |
| 按「請專員來說明」 | 已通知服務專員，請稍候，專員會到你的座位說明。登記內容：冷氣，開一陣子才不冷，出風量變小，沒有怪味。 |

結果：全部正確。症狀登記不呼叫 AI；流程面板記「範本：採用（程式組句）」。
