# 真實 AI 實測紀錄

用真的 Gemini（`gemini-3.5-flash-lite`）跑 `scripts/測試題_追問AI.md` 的 25 題（11/7 前是 21 題），加上接待摘要（王先生、林小姐各 3 次）。
執行：`npm run eval:21`（需要 `.env.local` 的 `GEMINI_API_KEY`）。每一題的問題、AI 原文回答、來源、答案檢查結果都在 `raw/` 的原始紀錄裡。

真的 AI 每次回答都不一樣，所以連跑多次，用通過率說話，不挑最好的一次。

修正前的實測沒有全過，那幾份紀錄被同檔名覆蓋，沒有保留：
- 誤攔：「煞車距離變長」被當成提到煞車皮；「若延後會降低煞車效能」被當成說可以延後。修正答案檢查，並加反例測試。

這些都沒有說錯維修結論。題目是修正時用過的，所以這 3 次是回歸驗證，不代表所有問法。
