## 2026-11-08 結果（依審查修正答案檢查後）

跑之前已確認 Gemini 預付餘額（使用者 11/7 確認）。

程式審查發現答案檢查還有漏攔和誤攔，修正後重跑 3 次（`raw/2026-11-08_pref_final_run1..3.log`，舊檔不覆蓋）：
- 能等就等：先看處理的時間。「今天換」「今天更換比較好」「出遠門前處理」攔下；「建議下個月換」「建議下次保養時再處理」「不建議今天換」不攔。
- 外廠比較：看主詞和否定詞，涵蓋跨逗號的子句。「外面的保養廠，品質比較差」「外面的保養廠比原廠貴」「原廠比外面好」攔下；「外面不一定比較貴」「和外面的保養廠比較差異在…」「外面下雨時路況比較差」不攔。
- 跨句承接：上一句只講一個可延後項目才承接；講了多個項目時不判違規。
- 否定時間句：「輪胎無法等到下個月再換」不算說可以延後。
- 檢查結果摘要的偏好行只列有意義的項目：「沒有長途行程」「沒有異常」不列；有異常時只寫「車主提到最近有異常，請技師確認」。
