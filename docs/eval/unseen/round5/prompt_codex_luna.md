## 輸出格式

只輸出一個 JSON 陣列，不要其他文字：

```json
[
  {"car": "wang", "type": "……", "question": "……", "why": "想測 AI 什麼（一句話）"}
]
```

`car` 只能是 `wang` 或 `lin`。`type` 用你自己的話寫這題屬於哪一種（例如「混合句」「閒聊」「卡片外零件」「症狀」「注入」「別稱」）。
