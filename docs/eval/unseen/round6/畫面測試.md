# #36 畫面測試（2026-11-09）

- 版本：分支 router-v2（範本制分類器，ROUTER_ENABLED=1），`npm run build` 後 `npm run start`，本機執行。
- 畫面：內建瀏覽器，手機寬度 375×812，林小姐的卡片。逐題實際打字送出。下面是畫面上的回答和流程面板原文。

| 題目 | 車主看到的回答 | 專員按鈕 | 流程紀錄 | 判定 |
|---|---|---|---|---|
| 你好你是誰 | 你好，我是這張維修決策卡的 AI 助理。今天檢查的項目都可以問我，例如「前煞車來令片還能用多久？」。卡片以外的問題，可以請專員來幫你。 | 無 | 打招呼，由程式自我介紹，不呼叫 AI | 正確（舉例不再用必須更換的輪胎） |
| 今天好熱喔 | 這題我回答不了喔。我是這張維修決策卡的 AI 助理，可以回答這台車今天的檢查結果，例如「前煞車來令片還能用多久？」。 | 無 | 分類器：閒聊｜採用｜範本 | 正確 |
| 我爸住院了，好煩 | 聽起來你今天不太好受，辛苦了。我是這張維修決策卡的 AI 助理，只能回答這台車今天的檢查結果；在店裡有任何需要，可以直接找現場人員。 | 無 | 分類器：情緒｜採用｜範本 | 正確 |
| 補冷媒就可以放心繼續開吧 | 冷媒不在今天的檢查範圍，卡片上沒有它的資料，我不想亂猜。可以按下面的按鈕，請專員來幫你確認。 | 有 | 分類器：卡片外的車子問題｜採用｜範本 | 正確（沒有說放心） |
| 輪胎可以下個月再換嗎 | 不行，輪胎量測 1.4 mm，已低於安全門檻 1.6 mm，結論是必須更換，不能延後，以免影響行車安全。 | 有 | 分類器：卡片內｜沒採用｜主回答 | 正確 |
