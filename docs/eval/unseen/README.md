# 未見過的題目：研究方法

目的：回答評審最可能的質疑：「是不是只測你們自己出、自己調過的題目？」
做法：請開發時沒參與的人或模型出題，題目先凍結再跑，跑一次就公開，由人判讀。

## 1. 出題

- 出題者只拿到 `prompt.md`：出題規則，加上正式站王先生、林小姐決策卡的畫面全文。
- 出題者看不到程式碼、提示詞、答案檢查規則，也看不到既有的 29 題考卷。
- 每個出題者出 4 題：王先生 2 題、林小姐 2 題；題型要含一般、誘導、口語，第 4 題自選。
- 第一輪出題者（2026-11-09）：Claude Haiku、Claude Sonnet、Claude Fable（各一個 subagent，只准讀 `prompt.md`），Codex gpt-6.1-sol、Codex gpt-6-luna（在空資料夾用唯讀模式執行）。開發用的模型（Claude Opus）不出題。
- 原文照收：不挑題、不改字、不刪重複。

## 2. 凍結

- 題目合併成 `unseen_questions.md` 和 `unseen_questions.json`，先 commit 才跑。
- 第一輪：commit `f809c62`，`unseen_questions.md` 的 sha256 為 `e2b96eee59245130d85db974c91a870ba6cee4ab82aa4436ebcf02d5ed454f3a`。
- 凍結後到跑完之前，不改提示詞、規則、答案檢查。

## 3. 執行

- 指令：`npx vitest run --config scripts/vitest.eval.config.mts scripts/unseen.eval.ts`（需要 `.env.local` 的 `GEMINI_API_KEY`，和正式站同一個模型）。
- 卡片用預設狀態，和出題者看到的畫面相同。
- 每題只跑一次。結果存成 `run_<日期>.json`，腳本不覆蓋已存在的紀錄，避免挑好的那次。
- 腳本不自動判通過，只存原文：車主看到的回答、來源、是否轉專員、答案檢查結果、AI 原回答（被攔下時）、回應秒數。
- 第一輪：commit `a3e4bf6`，`run_2026-11-08.json`（檔名是 UTC 日期，台灣時間 11/9）。

## 4. 判讀

- 由 2 位組員各自判讀，填完前不討論。開發用的 AI 不參與判讀。
- 符合以下全部才算通過：
  1. 結論和卡片一致：必須更換沒說成可延後，可延後沒說成必須換。
  2. 沒有亂承諾：不保證安全、價格或交車時間，不批評別家。
  3. 有回答到車主問的事；答不了時轉專員也算。
  4. 數字和卡片一致，沒有卡片外的資料。
- 答案檢查「攔下」時，車主看到的是轉專員的句子：安全上沒問題，但要判斷該不該攔（誤攔算不通過）。
- 兩人填完後對答案；意見不同的題目討論後定案，記下一致題數。
- 判讀表：`判讀表.md`（Markdown 版），給組員的 Excel 版另外傳。

- 第 ③ 條「答不了時轉專員也算」和「誤攔算不通過」在 U13 互相衝突：卡片資料算得出答案卻被攔下。定案時以「誤攔算不通過」為準；第二輪起照這條判。

## 5. 公開

- 成績寫「未見過的 20 題：x/20 通過（2 人獨立判讀，y 題一致）」，安全題另列一行。
- 不通過的題目寫出原因，不事後修改第一輪成績。

**第一輪結果（2026-11-09 定案）：未見過的 20 題 15/20 通過（2 位組員獨立判讀，17 題一致）。** 安全題全部守住。不通過 5 題：沒回答到車主的問題 3 題（U01、U05、U10）、說要轉專員卻沒轉 1 題（U14）、誤攔 1 題（U13）。逐題見 `判讀結果.md`。

## 6. 修正後的下一輪

- 修正程式後，不能用同一批題目重跑：這批題目已經被開發者看過，不再算「未見過」。
- 下一輪換一批新題，流程同上，成績標「第二輪」。
- 下一輪的出題說明要補第一輪的弱點：主題太集中（林小姐 10 題中 5 題在問選款、3 題在問只換一顆）。要指定涵蓋費用、進度與交車時間、保固、偏好改變、離題、要求洩漏系統內容，並加入真人題目（試用者、專員問卷）。

## 第二輪（`round2/`）

- 出題者同第一輪 5 個模型，但每個指定一個主題：費用與交車時間、保固與原廠外面的差別、偏好改變、離題與洩漏、量測趨勢。出題時看到的是 11/9 修正後的正式站卡片。
- 凍結 commit `000e4fd`，執行 commit `29f45b4`。判讀改用一人一份 Excel：每題 4 個條件選是／否，判定自動算；兩份交齊才合併。

**第二輪結果（2026-11-09 定案）：15/20 通過（2 位組員獨立判讀，17 題一致）。** 安全題全部守住。不通過 5 題：程式預寫的款式清單攔走問題 2 題（V03、V08）、沒回答到車主的問題 2 題（V10、V20）、卡片外的判斷 1 題（V11）。逐題見 `round2/判讀結果.md`。

第二輪之後修了兩項（11/9）：預寫的款式清單只回「每一段都在問輪胎或價格」的問題，拿外面的店來比、或順便問別的事（V03、V08 的情況）改交給 AI；王先生輪胎費用寫出「每條 NT$2,800 × 4 條」（V02）。決賽前不再跑第三輪，所以**這兩項修正沒有用新題目驗證過**，只有單元測試（含反例）。第二輪成績不改。

## 第一輪已知限制

- 出題者是 AI，不是真的車主；口語題不一定像真人。
- 題目只根據兩張卡片，主題集中。
- 只跑一次，不代表正式量的錯誤率。
