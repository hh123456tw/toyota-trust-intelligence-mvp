# A/B 盲評：正式站（d0e574e）對像真人助理版（t37-symptom）

兩版對同一批 40 題的回答，交給兩位判讀者盲評。判讀者只看 A／B，不知道哪版新。兩份都交齊才解盲。

## 檔案

- `make_packet.py`：讀 `../run_baseline_d0e574e.json`（舊）和 `../run_human_t37symptom.json`（新），每題用固定種子（37）決定哪版標 A，產生 `judge_packet.md` 和 `ab_key.json`。盲評包只有車、題號、類別、多輪前幾句、A／B 回答（含症狀登記題目、是否轉專員），開頭附兩台車的卡片事實給 (d) 項對照。腳本會檢查盲評包沒有 commit、檔名、trace 這類字。
- `ab_key.json`：題號 → A 是哪版。判讀時不給判讀者。
- `judge_fable.json`：Claude Fable 的判讀。
- `judge_codex_sol.txt`：Codex gpt-6.1-sol 的判讀（JSON）。指令：`codex exec --skip-git-repo-check -m gpt-6.1-sol -s read-only -C <只放盲評包和 rubric.md 的空資料夾> -o judge_codex_sol.txt -`，提示詞從 stdin 傳入。放空資料夾是為了讓它讀不到 `ab_key.json` 和結果檔。
- `unblind.py`：解盲，印出下面的表。

  理由：拿行車摘要推測異音原因。
